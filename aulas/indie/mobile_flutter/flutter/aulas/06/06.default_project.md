# Recriando o Projeto Inicial e as Diferenças Entre Stateless e Statefull Widgets

Nesta aula vamos recriar o projeto inicial do contador de vezes que um botão foi pressionado.

Na primeira parte iremos usar o mesmo `StatelessWidget` que usamos em todas as aulas. Veremos então que aparentemente o botão não consegue modificar a tela.

Depois então vamos mudar de `StatelessWidget` para `StatefulWidget` e veremos que o botão funcionará. 

O motivo disso é que o `StatelessWidget` **não atualiza a tela** quando há uma mudança de algum estado da classe, enquanto que o `StatefulWidget` atualiza.


## Anatomia de um `StatelessWidget`

Criando um projeto **vazio** podemos ver a seguinte estrutura

###### Projeto Vazio de Flutter
```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MainApp());
}

class MainApp extends StatelessWidget {
  const MainApp({super.key});

  @override
  Widget build(BuildContext context) {
    return const MaterialApp(
      home: Scaffold(
        body: Center(
          child: Text('Hello World!'),
        ),
      ),
    );
  }
}
```

A função do sistema `void runApp(Widget app)` recebe qualquer `Widget` e inicializa o projeto por este.

Neste caso a classe `MainApp` é um `StatelessWidget`, mais especificamente
`abstract class StatelessWidget extends Widget`, 
segundo a documentação é "uma widget que não depende da **mudança** de seu estado"
estado aqui pode ser entendido como os valores de seus atributos.

O seu método abstrato é `Widget build(BuildContext context)` que deve retornar os elementos que compõe o `MainApp`

## Recriando (*aproximadamente*) a Primeira Tela Sem Funcionamento

Vamos usar o `StatelessWidget` para recriar o exemplo inicial, mas perceba que **por enquanto não conseguiremos fazer funcionar** antes de migrar para o `StatefulWidget`

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MainApp());
}

class MainApp extends StatelessWidget {
  const MainApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: CounterApp(),
    );
  }
}

class CounterApp extends StatelessWidget{
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text("Meu App Contador"),
        backgroundColor: Colors.blueAccent,
      ),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text("O botão foi pressionado"), 
            Text("0 vezes", style: TextStyle(fontSize: 20, ),),
          ],
        ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: ()=>null, 
        child: Icon(Icons.add),
      ),
    );
  }
}
```

Temos somente a aparência do aplicativo, agora vamos **tentar** fazer funcionar: criaremos uma variável (um atributo da classe `CounterApp`) que aumentará de valor sempre que o botão for pressionado. 

Perceba que o contador aumenta mas a tela não atualiza

```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MainApp());
}

class MainApp extends StatelessWidget {
  const MainApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: CounterApp(),
    );
  }
}

class CounterApp extends StatelessWidget{
  int count = 0;
  void increaseCounter(){
    count++;
    print("agora o counter=$count");
  }
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text("Meu App Contador"),
        backgroundColor: Colors.blueAccent,
      ),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text("O botão foi pressionado"), 
            Text("${count} vezes", style: TextStyle(fontSize: 20, ),),
          ],
        ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: increaseCounter, 
        child: Icon(Icons.add),
      ),
    );
  }
}
```







## Anatomia de um `StatefulWidget`

Para que a tela seja modificada precisamos que ela **esteja em um `StatefulWidget`**

Segundo a documentação, um `StatefulWidget` é uma `Widget` que tem um estado mutável, ou seja, que pode ser modificado durante seu tempo de vida.

`abstract class StatefulWidget extends Widget`

Seu método abstrado é `State createState()` que retorna um `State`.
Precisamos que a parte que muda seja um `abstract class State<T extends StatefulWidget>`

Quando algum atributo for modificado, precisará estar dentro do método `setState(fn)`, da classe `State`, que recebe uma função.


## Fazendo a Tela Funcionar


Vamos converter o exemplo anterior para um `StatefulWidget`


```dart
import 'package:flutter/material.dart';

void main() {
  runApp(const MainApp());
}

class MainApp extends StatelessWidget {
  const MainApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: CounterApp(),
    );
  }
}

class CounterApp extends StatefulWidget{
  @override
  State<StatefulWidget> createState() => CounterAppState();
}

class CounterAppState extends State<CounterApp>{
  int count = 0;
  void increaseCounter(){
    count++;
    print("agora o counter=$count");
  }
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text("Meu App Contador"),
        backgroundColor: Colors.blueAccent,
      ),
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Text("O botão foi pressionado"), 
            Text("${count} vezes", style: TextStyle(fontSize: 20, ),),
          ],
        ),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(increaseCounter), 
        child: Icon(Icons.add),
      ),
    );
  }
  
}
```

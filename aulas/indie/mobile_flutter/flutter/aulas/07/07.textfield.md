# TextField

Nesta aula vamos ver como funciona o `TextField` no Flutter.

O `TextField` é uma caixa de entrada de texto que serve para o usuário escrever um texto curto para o programa processar.

Nesta aula vamos ver o básico para 
- Colocar um label no `TextField`
- Acessar o texto que o usuário digitou
- Escutar o `TextField` para cada tecla digitada

## Criando um `TextField` com uma etiqueta (label)

Para criar um objeto `TextField` basta chamar o constructor do próprio `TextField()`.

Podemos *decorar* este elemento com alguns atributos estéticos usando o atributo `decoration: InputDecoration()`.

Para criar uma etiqueta **dentro** do `TextField` usamos o atributo `hintText`:

```dart
TextField(      
    decoration: InputDecoration(
        hintText: "Seu Nome", 
    ),
), 
```

### Uma Etiqueta que Não Some

Temos também como criar uma etiqueta que não some, mas vai **para cima** do `TextField` quando o usuário começar a digitar. Usando o `label` ao invés do `hintText` teremos este efeito.

## Acessando o Texto do `TextField`

Para acessar o texto do `TextField` devemos criar um objeto que controla o texto chamado `TextEditingController`. 

Este objeto é enviado para o contructor do `TextField` que você quer ter acesso.

Para acessar o texto basta usar o atributo `text` do `TextEditingController`.

Observe o programa abaixo que pede o nome e o sobrenome para o usuário. Após apertar o botão o nome completo aparece na tela.



```dart
import 'package:flutter/material.dart';


class TextFieldExamplePage extends StatefulWidget{
  @override
  State<StatefulWidget> createState() => TextFieldExampleState();
}

class TextFieldExampleState extends State<TextFieldExamplePage>{

  String nome = "";
  String sobrenome = "";
  String nomeCompleto = "";

  TextEditingController textNomeController = TextEditingController(text: 'Ana');
  TextEditingController textSobrenomeController = TextEditingController(text: 'Maria');

  void atualizaNomeCompleto(){
    setState(() {
      nome = textNomeController.text;
      sobrenome = textSobrenomeController.text;
      nomeCompleto = "$nome $sobrenome";
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text("TextField", 
          style: TextStyle(fontSize: 30, fontWeight: FontWeight(20)),
        ),
        backgroundColor: Colors.blueAccent,
      ),
      body: Center(
        child: Padding(
          padding: EdgeInsetsGeometry.all(20), 
          child:  Column(
            children: [
              TextField(
                controller: textNomeController,
                decoration: InputDecoration(
                  label: Text("Seu Nome"),
                ),
              ), 
              TextField(
                controller: textSobrenomeController,
                decoration: InputDecoration(
                  label: Text("Seu Sobrenome"),
                ),
              ), 
              Text("Nome Completo: ${nomeCompleto}"), 
              ElevatedButton(
                onPressed: atualizaNomeCompleto, 
                child: Text('Mostrar Nome Completo'),
              ),
            ],
          ),
        )
      ),
    );
  }
}

```

## Lendo `TextField` em Tempo Real

Existe a possibilidade de executar uma função a cada modificação do `TextField` preenchendo o atributo `onChanged`. Neste atributo devemos escrever uma função que recebe a string que está escrita no `TextField` sem a necessidade de acessar através de um controlador

```dart
TextField(
    onChanged: (value) => {
        setState(() {
            nome = value;
            nomeCompleto = "$nome $sobrenome";
        })
    },
    decoration: InputDecoration(
        hintText: "Seu Nome", 
    ),
), 
TextField(
    onChanged: (value) => {
        setState(() {
            sobrenome = value;
            nomeCompleto = "$nome $sobrenome";
        })
    },
    decoration: InputDecoration(
        label: Text("Seu Sobrenome")
    ),
), 
```

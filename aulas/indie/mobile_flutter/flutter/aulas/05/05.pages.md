# Criando Páginas Em Arquivos Separados e Navegação Entre Páginas

## Fazendo Uma Página Separada

Para a modularidade do aplicativo é essencial que possamos estruturar as páginas independente de seus conteúdo.

Nesta aula vamos separar a estrutura de uma página de seu conteúdo.

Vamos também fabricar outras páginas com a **mesma estrutura** mas **diferentes conteúdos**.

### Fazendo uma Tela em um arquivo só

Considere a seguinte página e separece a sua estrutura, à partir do `Scaffold` para uma classe em um arquivo separado.

###### main.dart
```dart
import 'package:flutter/material.dart';

String url = 'https://thumb.wikimedia.org/wikipedia/commons/thumb/3/37/Parque_Portugal_%2813%29.jpg/1280px-Parque_Portugal_%2813%29.jpg';
String placeName = 'Parque Portugal';
String placeText = 
'''
O Parque Portugal (conhecido popularmente como Lagoa do Taquaral ou Parque Taquaral) é um parque no bairro do Taquaral, na Região Leste de Campinas, no estado de São Paulo, no Brasil. É o parque mais famoso da cidade. Junto com o Lago do Café e a Praça Arautos da Paz, forma a mais importante zona de lazer da cidade. O parque recebe diariamente milhares de pessoas, entre moradores da cidade e turistas, principalmente aos finais de semana. No verão, o parque chega a receber 50 000 visitantes em uma semana
Dentre as atrações do parque, destacam-se sua grande lagoa, uma réplica da Caravela Anunciação, uma linha de bonde elétrico e uma concha acústica, além de pista de saibro para caminhada, ciclovia, cartódromo, quadras de futebol, basquete, vôlei e hóquei e uma ampla área verde. Aos domingos, entre 6 e 13 horas, a avenida ao redor do parque é fechada para veículos, ficando destinada ao ciclismo e lazer.
''';

void main() {
  runApp(MainApp());
}

class MainApp extends StatelessWidget{
  
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: HomePage(), 
    );
  }
}

class HomePage extends StatelessWidget{

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(placeName, ), backgroundColor: Colors.blueGrey,),
      body: Column(
        children: [
        Image.network(url, width: double.infinity, height: 200, fit: BoxFit.cover,), 
        Text(placeText), 
        ],
      ),
    );
  }
}
```

## Navegando Entre Páginas

Agora que sabemos fazer uma página separada de seu conteúdo, podemos fazer múltiplas páginas iguais usando a mesma estrutura e mudando apenas o conteúdo.

Mas primeiro vamos aprender como navegar entre páginas e vamos fazer um botão para que isto aconteça.

Para o botão vamos usar o `ElevatedButton`: um botão com estética trisimensional, onde precisamos setar os atributos `onPressed` que recebe uma função, e `child` que recebe o label que o botão terá.

Para fazer a navegação vamos usar o método `Navigator` do Flutter. Este método usa o `push` para carregar uma página por cima da página atual. O `push` recebe um `MaterialPageRoute` que contrói a página que queremos abrir.

Veja o modelo copiado da [documentação oficial](https://docs.flutter.dev/ui/navigation):
```dart
child: const Text('Open second screen'),
onPressed: () {
  Navigator.of(context).push(
    MaterialPageRoute<void>(
      builder: (context) => const SecondScreen(),
    ),
  );
},
```
### No seu aplicativo
Troque o main pelo seguinte main, onde fazemos um botão na tela inicial que irá criar e chamar a segunda página.

###### main.dart
```dart
import 'package:flutter/material.dart';
import 'package:navigation_page_example/places_page.dart';

String url = 'https://thumb.wikimedia.org/wikipedia/commons/thumb/3/37/Parque_Portugal_%2813%29.jpg/1280px-Parque_Portugal_%2813%29.jpg';
String placeName = 'Parque Portugal';
String placeText = 
'''
O Parque Portugal (conhecido popularmente como Lagoa do Taquaral ou Parque Taquaral) é um parque no bairro do Taquaral, na Região Leste de Campinas, no estado de São Paulo, no Brasil. O parque recebe diariamente milhares de pessoas, entre moradores da cidade e turistas, principalmente aos finais de semana. No verão, o parque chega a receber 50 000 visitantes em uma semana
Dentre as atrações do parque, destacam-se sua grande lagoa, uma réplica da Caravela Anunciação, uma linha de bonde elétrico e uma concha acústica, além de pista de saibro para caminhada, ciclovia, cartódromo, quadras de futebol, basquete, vôlei e hóquei e uma ampla área verde. Aos domingos, entre 6 e 13 horas, a avenida ao redor do parque é fechada para veículos, ficando destinada ao ciclismo e lazer.
''';


void main() {
  runApp(MainApp());
}

class MainApp extends StatelessWidget{
  
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: HomePage(), 
    );
  }
}


class HomePage extends StatelessWidget{
  
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            ElevatedButton(
              onPressed: () => Navigator.of(context).push(
                MaterialPageRoute<void>(
                  builder: (context) => MyPage(url, placeName, placeText)
                )
              ), 
              child: Text(placeName), 
            ),
          ],
        ), 
      ),
    );
  }
}

```



## Fazendo Múltiplas Páginas

Como exercício faça mais duas páginas com mais dois botões onde o usuário consiga escolher qual página entrar à partir da inicial.

##### Solução

###### main.dart
```dart
import 'package:flutter/material.dart';
import 'package:navigation_page_example/places_page.dart';

String urlTaquaral = 'https://thumb.wikimedia.org/wikipedia/commons/thumb/3/37/Parque_Portugal_%2813%29.jpg/1280px-Parque_Portugal_%2813%29.jpg';
String placeNameTaquaral = 'Parque Portugal';
String placeTextTaquaral = 
'''
O Parque Portugal (conhecido popularmente como Lagoa do Taquaral ou Parque Taquaral) é um parque no bairro do Taquaral, na Região Leste de Campinas, no estado de São Paulo, no Brasil. É o parque mais famoso da cidade. Junto com o Lago do Café e a Praça Arautos da Paz, forma a mais importante zona de lazer da cidade. O parque recebe diariamente milhares de pessoas, entre moradores da cidade e turistas, principalmente aos finais de semana. No verão, o parque chega a receber 50 000 visitantes em uma semana
Dentre as atrações do parque, destacam-se sua grande lagoa, uma réplica da Caravela Anunciação, uma linha de bonde elétrico e uma concha acústica, além de pista de saibro para caminhada, ciclovia, cartódromo, quadras de futebol, basquete, vôlei e hóquei e uma ampla área verde. Aos domingos, entre 6 e 13 horas, a avenida ao redor do parque é fechada para veículos, ficando destinada ao ciclismo e lazer.
''';

MyPage pageTaquaral = MyPage(urlTaquaral, placeNameTaquaral, placeTextTaquaral);


String urlEstacao = 'https://thumb.wikimedia.org/wikipedia/commons/thumb/1/1a/Esta%C3%A7%C3%A3o_ferrovi%C3%A1ria_-_centro_cultural_de_Campinas_001.jpg/1280px-Esta%C3%A7%C3%A3o_ferrovi%C3%A1ria_-_centro_cultural_de_Campinas_001.jpg';
String placeNameEstacao = 'Estação Campinas';
String placeTextEstacao = 
'''
Estação Cultura “Prefeito Antônio da Costa Santos”, também conhecida como Estação de Campinas, Estação Central de Campinas ou Estação da Fepasa, é a antiga estação ferroviária central da cidade de Campinas, no interior do estado de São Paulo, no Brasil e desde 2002, funciona como um centro cultural.
Foi eleita, em 2007, uma das Sete Maravilhas da Cidade.
''';

MyPage pageEstacao = MyPage(urlEstacao, placeNameEstacao, placeTextEstacao);



String urlMercadao = 'https://thumb.wikimedia.org/wikipedia/commons/thumb/b/ba/Atras_do_Mercad%C3%A3o_-_panoramio.jpg/1280px-Atras_do_Mercad%C3%A3o_-_panoramio.jpg';
String placeNameMercadao = 'Mercado Municipal';
String placeTextMercadao = 
'''
Mercado Municipal de Campinas está localizado no centro de Campinas, no interior do estado de São Paulo, no Brasil.
''';

MyPage pageMercadao = MyPage(urlMercadao, placeNameMercadao, placeTextMercadao);

void main() {
  runApp(MainApp());
}

class MainApp extends StatelessWidget{
  
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: HomePage(), 
    );
  }
}


class HomePage extends StatelessWidget{

  List<MyPage> paginas = [pageTaquaral, pageEstacao, pageMercadao];
  
  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            for(MyPage p in paginas)
              ElevatedButton(
                onPressed: () => Navigator.of(context).push(
                  MaterialPageRoute<void>(
                    builder: (context) => MyPage(p.url, p.placeName, p.placeText)
                  )
                ), 
                child: Text(p.placeName), 
              ),
          ],
        ), 
      ),
    );
  }
}
```

# Componentes Assíncronos: Future e Async Await

Eventos **síncronos** são eventos que **ocorrem um depois do outro** e **um só começa depois que o outro** acabar. 

É o normal da programação, como a gente está acostumado a esperar que aconteça.

Eventos **assíncronos** são eventos que podem acontecer ao mesmo tempo (**em paralelo**), deixando que o sistema faça outras coisas enquanto um evento está calculando uma resposta.

Nesta seção vamos ver alguns métodos **assíncronos**:

## Future

A classe [Future](https://api.flutter.dev/flutter/dart-async/Future-class.html) é a classe resultado de uma computação assíncrona.

No exemplo abaixo usamos o constructor [Future.delayed](https://api.flutter.dev/flutter/dart-async/Future/Future.delayed.html) demorar alguns segundos para imprimir a mensagem `Download completo`

```dart
void fazendoDownload(String file, int time){
  print('Abrindo conexao para fazer download de $file por $time segundos');
  Future.delayed(
    Duration(seconds: time), 
    ()=>print('Download de $file terminou depois de $time segundos')
  );
  print('Fechando conexao do download de $file');
}

void main(){
  fazendoDownload('filmeA', 6);
  fazendoDownload('filmeB', 10);
  fazendoDownload('filmeC', 3);
  
}
```
###### Saída
```
Abrindo conexao para fazer download de filmeA por 6 segundos
Fechando conexao do download de filmeA
Abrindo conexao para fazer download de filmeB por 10 segundos
Fechando conexao do download de filmeB
Abrindo conexao para fazer download de filmeC por 3 segundos
Fechando conexao do download de filmeC
Download de filmeC terminou depois de 3 segundos
Download de filmeA terminou depois de 6 segundos
Download de filmeB terminou depois de 10 segundos
```

O `Future.delayed` vai demorar alguns segundos para imprimir a mensagem, mas **não vai bloquear o resto da função**.

Mas e se quisermos que alguma parte do resto da função **espere** a finalização de `Future`? Que espere para fechar a conexão depois que o download for feito, por exemplo.


## Await

O comando `await` espera o resultado do objeto `Future` e bloqueia o resto do método até que o resultado saia.

Observe que para usar o comando `await` precisamos marcar o método como `async`.

```dart
// para usar o comando await precisamos dizer
//    que o metodo eh async
void fazendoDownload(String file, int time) async {
  print('Abrindo conexao para fazer download de $file por $time segundos');
  Future<String> resultadoFuturo = Future<String>.delayed(
    Duration(seconds: time),
    () => 'Download de $file terminou depois de $time segundos',
  );
  // await em um objeto do tipo Future<T>
  //    vai esperar o rsultado, do tipo T
  String resultado = await resultadoFuturo;
  print(resultado);
  print('Fechando conexao do download de $file');
}

void main() {
  fazendoDownload('filmeA', 6);
  fazendoDownload('filmeB', 10);
  fazendoDownload('filmeC', 3);
}
```


```
Abrindo conexao para fazer download de filmeA por 6 segundos
Abrindo conexao para fazer download de filmeB por 10 segundos
Abrindo conexao para fazer download de filmeC por 3 segundos
Download de filmeC terminou depois de 3 segundos
Fechando conexao do download de filmeC
Download de filmeA terminou depois de 6 segundos
Fechando conexao do download de filmeA
Download de filmeB terminou depois de 10 segundos
Fechando conexao do download de filmeB
```

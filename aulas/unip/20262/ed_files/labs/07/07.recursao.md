# Recursão

Recursão é a técnica de definir uma função usando ela mesma.

Por exemplo, na matemática a função fatorial `n!`, definida para inteiros maiores que `0`, pode ser definida como
- base: `0` se `n=0`
- recursão: `n*((n-1)!)` se `n>0`

Em toda recursão temos um caso base, que é uma definição para um valor específico trivial, e a recursão, que é a definição baseada na própria definição aplicada a um valor menor.

## Exercícios

Use funções recursivas para resolver os seguintes exercícios

###### 1
Faça uma função que retorna o fatorial de um número inteiro.

###### 2
Faça uma função que recebe um array e imprimime todas as combinações de seus elementos, não importando a ordem.

###### 3
Faça uma função que recebe um array e imprimime todas as permutações de seus elementos, neste caso importa a ordem e toda permutação contem todos os elementos, só mudando a ordem.

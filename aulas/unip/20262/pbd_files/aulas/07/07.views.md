# Views[^fonte]

[^fonte]: https://www.w3schools.com/mysql/mysql_view.asp

Uma `View` é uma tabela virtual baseada no resultado de uma *query*.
A `View` contém linhas e colunas assim como uma tabela, mas seus dados são virtuais, espelhando os dados da tabela real.
A vantagem de criar uma `View` é poder criar uma combinação de duas tabelas sem precisar criar uma cópia de uma tabela.

## Propriedades

Você pode fazer comandos `SQL` e aplicar funções à uma `View` como se ela fosse uma tabela real.

Você pode inclusive modificar dados em uma `View` que estes dados serão modificados na tabela real, **mas somente se** essa `View` **não** é resultado de uma função de agregação com o comando `GROUPBY`.

## Sintaxe

Uma `View` pode ser criada usando o comando `CREATE VIEW` para criar uma `View` ou `CREATE OR REPLACE VIEW` para criar ou substituir uma `View`.

```sql
CREATE VIEW view_name AS
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```


```sql
CREATE OR REPLACE VIEW view_name AS
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```

## Usando View em Uma Query

O seguinte comando irá criar uma `View` com pizzas com o preço menor, ou igual, a 30.

```sql
CREATE VIEW pizzas_baratas_view AS
SELECT * FROM Pizzas
WHERE preco <= 30;
```

Fazendo a seguinte query podemos ver o resultado
```sql
SELECT * FROM pizzas_baratas_view;
```

###### pizzas_baratas_view
| id_pizza|nome|preco|
|---|---|---|
|1|Marguerita|10|
|2|Frango|20|

Vamos dobrar o preço de todas as pizzas da `View` `pizzas_baratas_view`
```sql
UPDATE pizzas_baratas_view 
SET preco=2*preco;
```
Observe o resultado da `View`

###### pizzas_baratas_view
| id_pizza|nome|preco|
|---|---|---|
|1|Marguerita|20|

Vemos que o preço dobrou e a pizza de Frango ficou mais cara que 30, saindo da `View`

Observe o resultado da tabela real e veja que as pizzas que estavam na `View` dobraram de preço enquanto que as que não estavam não dobraram.

###### Pizzas
| id_pizza|nome|preco|
|---|---|---|
|1|Marguerita|20|
|1|Frango|40|
|1|Calabresa|40|

## Usando View Com Join

Vamos fazer uma `View` relacionando a tabela de pizzas e pedidos

```sql
CREATE VIEW pizzas_pedidas_view AS
SELECT pedidos.id_pedido AS id_pedido, pedidos.id_cliente AS id_cliente, 
pizzas.id_pizza AS id_pizza, pizzas.nome AS nome_pizza, pizzas.preco AS preco
FROM pizzas JOIN pedidos
ON pizzas.id_pizza=pedidos.id_pizza;
```


###### Pizzas_Pedidas_View
| id_pedido|id_cliente|id_pizza|nome_pizza|preco|
|---|---|---|---|---|
|1|1|1|Marguerita|20|
|2|1|1|Marguerita|20|
|3|1|2|Frango|40|
|4|2|1|Marguerita|20|

Falta apenas adicionar nesta tabela o nome do cliente, que faremos na próxima seção.

## Relacionando (`Join`) 3 Tabelas com o Auxilio do `View`

No caso desta aula, onde temos 3 tabelas relacionadas, para relacionar o nome do cliente com o nome da pizza, precisamos necessarimente relacionar as 3 tabelas.

Fazer um `Join` de 3 tabelas é complicado, mas podemos usar a `View` anterior, que relaciona Pedidos com Pizzas e relacionar com Clientes

```sql
CREATE VIEW pizzas_pedidas_clientes_view AS
SELECT pizzas_pedidas_view.id_pedido, pizzas_pedidas_view.id_cliente, 
pizzas_pedidas_view.id_pizza, pizzas_pedidas_view.nome_pizza, pizzas_pedidas_view.preco,
clientes.nome as nome_cliente
FROM pizzas_pedidas_view JOIN clientes
ON pizzas_pedidas_view.id_cliente=clientes.id_cliente;
```

Agora temos uma `View` com todos os dados que precisamos para fazer qualquer operação que envolva a relação entre pizzas e clientes.

###### Pizzas_Pedidas_View
| id_pedido|id_cliente|id_pizza|nome_pizza|preco|nome_cliente|
|---|---|---|---|---|---|
|1|1|1|Marguerita|20|Ana|
|2|1|1|Marguerita|20|Ana|
|3|1|2|Frango|40|Ana|
|4|2|1|Marguerita|20|Beto|

Podemos ver o quanto cada cliente gastou em pizzas

```sql
SELECT id_cliente, nome_cliente, SUM(preco) 
FROM pizzas_pedidas_clientes_view 
GROUP BY id_cliente;
```

###### Pizzas_Pedidas_View
|id_cliente|nome_cliente|SUM(preco)|
|---|---|---|
|1|Ana|80|
|2|Beto|20|

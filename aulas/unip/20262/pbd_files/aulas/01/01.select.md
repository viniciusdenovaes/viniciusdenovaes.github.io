# SELECT

[fonte](https://www.w3schools.com/mysql/mysql_select.asp)

Nesta aula vamos ver as possibilidades de *selecionar* dados de **uma** tabela. 

Ainda não veremos como cruzar informações entre duas tabelas, mas sim as formas de visualizar dados de uma única tabela.

O comando `SELECT` é usado para fazer uma busca (também chamada de *query*) por informação em uma tabela.

## Sintaxe

```sql
SELECT column1, column2, ...
FROM table_name;
```

O comando `SELECT` é formado pelo nome da colunas que você quer visualizar seguido de `FROM` e o nome da tabela que você quer fazer a busca.

Por exemplo:

```sql
SELECT ra, nome FROM Alunos;
```

Mostra **todas as linhas** e as colunas `ra` e `nome` da tabela `Alunos`.

Caso você queira mostrar **todas** as colunas, você pode usar

```sql
SELECT * FROM Alunos;
```

## SELECT DISTINCT

[fonte](https://www.w3schools.com/mysql/mysql_select_distinct.asp)

O `SELECT DISTINCT` mostra todas as linhas distintas.

Então o comando

```sql
SELECT DISTINCT bairro FROM Alunos;
```

Mostrará todos os bairros **diferentes** da tabela `Alunos`.

```sql
SELECT DISTINCT bairro, cidade FROM Alunos;
```

Mostrará todos os bairros **e** cidades **diferentes** da tabela `Alunos`. Note que o mesmo bairro pode aparecer mais de uma vez, assim como a mesma cidade, mas não a mesma dupla de `(bairro, cidade)`

## LIMIT e OFFSET

Caso o banco de dados tenha muitos dados pode ser que o resultado de uma pesquisa sejam dados demais.

É possível limitar quantos resultados vão aparecer na tela usando o comando `LIMIT`

```sql
SELECT * FROM Alunos
LIMIT 3;
```

Este comando limitará o resultado em 3 linhas: mostrará apenas as 3 primeiras linhas.

Caso você queira pular linhas, você pode usar o comando `OFFSET`

```sql
SELECT * FROM Alunos
LIMIT 3 OFFSET 4;
```

Mostrará apenas 3 alunos à partir do 5 alunos (pulará 4 alunos)

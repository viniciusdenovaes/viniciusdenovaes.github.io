# SELECT WHERE

Usando o comando `WHERE` podemos filtrar a pesquisa.

## Sintaxe

```sql
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```

Seleciona as colunas da tabela obedecendo a condição `condition`.

Por exemplo

```sql
SELECT *
FROM Alunos
WHERE ra='A123';
```

Seleciona o aluno com ra A123;

```sql
SELECT *
FROM Alunos
WHERE ra<>'A123';
```

Seleciona **todos os alunos** com ra **diferente** de A123;

```sql
SELECT *
FROM Notas
WHERE np1>7;
```

Seleciona todas as ocorrências em que o aluno tirou mais que 7 na NP1;

## Operadores Lógicos (`AND`, `OR` e `NOT`)

Podemos combinar condições com operadores lógicos:

```sql
SELECT *
FROM Notas
WHERE np1>=7 AND np2>=7;
```

Seleciona todas as ocorrências em que o aluno tirou uma nota maior ou igual a 7 na NP1 **e** na NP2;


```sql
SELECT *
FROM Notas
WHERE np1>=7 OR np2>=7;
```

Seleciona todas as ocorrências em que o aluno tirou uma nota maior ou igual a 7 na NP1 **ou** na NP2;



```sql
SELECT *
FROM Enderecos
WHERE NOT bairro=Cambuí;
```

Seleciona todos os endereços onde o bairro não é Cambuí.



## BETWEEN

O comando `BETWEEN` é a mesma coisa que fazer um intervalo usando `AND` incluindo os extremos.


```sql
SELECT *
FROM Notas
WHERE np1 BETWEEN 7 AND 9;
```
Seleciona todas as ocorrências em que o aluno tirou uma nota maior **ou igual** a 7, e menor **ou igual** a 9 na NP1


## LIKE

O comando `LIKE` procura padrões no texto, por exemplo

```sql
SELECT * FROM Alunos
WHERE nome LIKE 'a%';
```

Mostra todos os alunos que tem um nome que **começa com a letra** `a`, ignorando diferença entre caixa alta ou baixa (*Case Insensitive*)

Temos os símbolos especiais:
- `%` - quer dizer zero ou mais quaisquer characters
- `_` - exatamente um character

Outro exemplo 

```sql
SELECT * FROM Alunos
WHERE nome LIKE '%ar%';
```

Todos nomes que tem a substring `ar`, pode exemplo Arthur ou Marta.


## IN

Compara valores dentro de uma lista

```sql
SELECT * FROM Alunos
WHERE nome IN ('Ana','Maria');
```

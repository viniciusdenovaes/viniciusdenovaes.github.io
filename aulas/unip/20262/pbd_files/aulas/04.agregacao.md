# Agregação[^fonte]

Funções de agregação são aplicadas em um conjunto de dados definidos por um grupo.

Considere as seguintes tabelas

##### Alunos
| ra|nome|
|---|---|
|a12|Ana|
|b12|Beto|
|c12|Carla|
|d12|Dani|

##### Cursos
| id|nome|
|---|---|
|c01|Java|
|c02|Python|


##### Notas
| ra|curso|np1|np2|
|---|---|---|---|
|a12|c01|8|7|
|b12|c01|4|3|
|c12|c01|9|8|
|d12|c01|3|0|
|a12|c02|7|8|
|b12|c02|3|4|
|c12|c02|8|9|
|d12|c02|7|10|

## Funções de Agregação

### Função `MAX`

A função `MAX` aplicada às notas NP1 da tabela Notas mostrará a maior nota NP1.

```sql
SELECT MAX(np1) FROM Notas;
```
|MAX(np1)|
|---|
|9.0|


### Função `MIN`

A função `MIN` aplicada às notas NP1 da tabela Notas mostrará a menor nota NP1.

```sql
SELECT MIN(np1) AS np1_minima FROM Notas;
```
|np_minima|
|---|
|3.0|

Perceba que podemos mudar o nome da coluna resultado com `MIN(np1) AS np1_minima`.

### Função `SUM` (Soma)

A função `SUM` aplicada às notas NP1 da tabela Notas somará todas as notas.

```sql
SELECT SUM(np1) FROM Notas;
```
|SUM(np1)|
|---|
|49.0|

### Função `AVG` (Média)

A função `AVG` calcula a média.

```sql
SELECT AVG(np1) AS media_np1 FROM Notas;
```
|media_np1|
|---|
|6.125|




### Função `COUNT`

A função `COUNT` conta quantos resultados tiveram a pesquisa.

O comando a seguir conta quantos alunos existem na tabela `Alunos`

```sql
SELECT COUNT(*) AS qtd_alunos FROM Alunos;
```
|qtd_alunos|
|---|
|4|

A função `COUNT` pode receber um argumento opcional `DISTINCT` para contar a quantidade de ocorrências diferentes existem em dada coluna.

Por exemplo, na tabela de `Notas` temos 8 linhas.

Se contarmos a quantidade de linhas na coluna de `ra` termos 8 linhas:

```sql
SELECT COUNT(ra) FROM Notas;
```
|COUNT(ra)|
|---|
|8|

Mas se contarmos as linhas **distintas** teremos 4, por que temos 4 alunos distintos.

```sql
SELECT COUNT(DISTINCT ra) AS qtd_ra FROM Notas;
```
|qtd_ra|
|---|
|4|

Podemos fazer o mesmo com o curso para vermos quantos cursos temos na tabela de notas:

```sql
SELECT COUNT(DISTINCT curso) AS qtd_curso FROM Notas;
```
|qtd_curso|
|---|
|2|


## Agrupamento

Ao invés de usar uma função para simplesmente calcular a média todas as notas NP1 de todos os cursos e de todos os alunos, podemos calcular a média das notas **para cada aluno**. 

Para fazer isso podemos pedir para **agrupar por alunos**.

Podemos ver as médias das NP1 de cada **aluno**
```sql
SELECT ra, AVG(np1) AS medias FROM Notas GROUP BY ra;
```
ra|medias
|---|---|
|a12|7.5|
|b12|3.5|
|c12|8.5|
|d12|5.0|

Ao pedir para **agrupar por ra**, o resultado será separado em grupos definidos pelo ra, e aplicará a função dentro de cada grupo isoladamente.

Se, por exemplo, você quiser saber a menor nota NP1 de cada aluno:

```sql
SELECT ra, MIN(np1) AS minimo FROM Notas GROUP BY ra;
```
ra|minimo
|---|---|
|a12|7.0|
|b12|3.0|
|c12|8.0|
|d12|3.0|

Se você quiser saber a menor nota NP1 de cada curso:

```sql
SELECT curso, MIN(np1) AS minimo FROM Notas GROUP BY curso;
```
curso|minimo
|---|---|
|c01|3.0|
|c02|3.0|


Se eu quiser contar quantos cursos cada aluno fez:

```sql
SELECT ra, COUNT(DISTINCT curso) AS qtd_curso FROM Notas GROUP BY ra;
```

ra|minimo
|---|---|
|a12|2|
|b12|2|
|c12|2|
|d12|2|

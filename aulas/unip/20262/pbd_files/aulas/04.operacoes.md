## Operações

Podemos fazer operações entre duas colunas.

Por exemplo, o comando a seguir exibe uma coluna a mais com o resultado da soma das notas de NP1 e NP2

```sql
SELECT ra, curso, np1, np2, np1 + np2 AS soma FROM Notas;
```
|ra|curso|np1|np2|soma
|---|---|---|---|---
|a12|c01|8.0|7.0|15.0|
|b12|c01|4.0|3.0|7.0|
|c12|c01|9.0|8.0|17.0|
|d12|c01|3.0|0.0|3.0|
|a12|c02|7.0|8.0|15.0|
|b12|c02|3.0|4.0|7.0|
|c12|c02|8.0|9.0|17.0|
|d12|c02|7.0|10.0|17.0|

O comando a seguir irá calcular a média de cada aluno para cada matéria

```sql
SELECT ra, curso, np1, np2, (np1 + np2)/2 AS media FROM Notas;
```

|ra|curso|np1|np2|media
|---|---|---|---|---
|a12|c01|8.0|7.0|7.50000|
|b12|c01|4.0|3.0|3.50000|
|c12|c01|9.0|8.0|8.50000|
|d12|c01|3.0|0.0|1.50000|
|a12|c02|7.0|8.0|7.50000|
|b12|c02|3.0|4.0|3.50000|
|c12|c02|8.0|9.0|8.50000|
|d12|c02|7.0|10.0|8.50000|


## LEAST e GREATEST (Maior e Menor)

A função `LEAST` retorna o menor dos seus argumentos recebidos.

```sql
SELECT ra, curso, np1, np2, LEAST(np1, np2) AS menor_nota FROM Notas;
```

|ra|curso|np1|np2|menor_nota
|---|---|---|---|---
|a12|c01|8.0|7.0|7.0|
|b12|c01|4.0|3.0|3.0|
|c12|c01|9.0|8.0|8.0|
|d12|c01|3.0|0.0|0.0|
|a12|c02|7.0|8.0|7.0|
|b12|c02|3.0|4.0|3.0|
|c12|c02|8.0|9.0|8.0|
|d12|c02|7.0|10.0|7.0|


A função `GREATEST` retorna o maior.

# Stored Procedure e Triggers

Nesta aula vamos tratar de um problema e ver como as funções de *Stored Procedure* e *Trigger* podemos nos ajudar.

## Stored Procedure[^sp_w3][^sp_dev]
[^sp_w3]:[fonte w3schools](https://www.w3schools.com/mysql/mysql_stored_procedures.asp)
[^sp_dev]:[fonte dev mysql](https://dev.mysql.com/doc/refman/9.7/en/create-procedure.html)

Um *Stored Procedure* é um código pré-compilado e salvo que pode ser reusado.

Vamos considerar a seguinte tabela criada pelos [comandos](ddl_pizzas.txt)

Vamos supor que precisamos fazer o comando de buscar uma pizza pelo nome.

Precisaremos escrever

```sql
SELECT * FROM Pizzas
WHERE nome LIKE '%frango%';
```

Para que não precisemos escrever o mesmo comando com frequência, podemos criar um *stored procedure*

##### sintaxe
```sql

DELIMITER //

CREATE PROCEDURE busca_pelo_nome(
    IN param1 datatype, 
    IN param2 datatype,
    OUT saida datatype
    )
BEGIN
  -- SQL_statements to be executed
  SELECT column1, column2
  FROM table_name
  WHERE columnN = paramN;
END //

DELIMITER ;
```

##### Explicação

O comando `CREATE PROCEDURE` cria um procedimento com o nome `procedure_name`, este procedimento pode ter argumentos de entrada.

A definição do procedimento está entre o comando `BEGIN` e `END`. Dentro do procedimento podemos escrever quaisquer comandos.

O uso do `DELIMITER` é para redefinir o que é o final de um comando para o sql. Neste caso mudamos o final do comando para `//` para não confundir com o `;` de dentro da definição do procedimento.

Vamos ver um exemplo:

```sql
DELIMITER //

CREATE PROCEDURE busca_pelo_nome(IN nome_buscado VARCHAR(20))
BEGIN
  SELECT * FROM Pizzas
  WHERE nome LIKE CONCAT('%', nome_buscado, '%');
END //

DELIMITER ;
```

Agora podemos chamar o procedimento com o comando `CALL`.

```sql
CALL busca_pelo_nome('frango');
```

Um procedimento pode ter uma saída.

```sql
DELIMITER //

CREATE PROCEDURE calcula_media_preco(OUT media FLOAT)
BEGIN
  SELECT AVG(preco) INTO media FROM Pizzas;
END //

DELIMITER ;
```

Agora podemos ver o valor da variável

```sql
CALL calcula_media_preco(@media);
SELECT @media;
```


| @media|
|---|
|30.714284896850586|


Podemos aumentar o preço de todos que estão abaixo da média.

```sql
DELIMITER //

CREATE PROCEDURE aumenta_abaixo_media(IN porcentagem DECIMAL)
BEGIN
  CALL calcula_media_preco(@media);

  UPDATE Pizzas
  SET preco = preco + (preco)*(porcentagem/100)
  WHERE preco < @media;
END //

DELIMITER ;
```


Chamando o procedimento com o valor 20 teremos:

```sql
CALL aumenta_abaixo_media(20);
```

Triggers são comandos SQL salvos no banco de dados, ligados à uma tabela, que são ativados quando certos eventos ocorrem.

Por exemplo, você pode criar um comando para acontecer sempre que houver uma ação de atualização de uma tabela.

## Eventos Permitidos

Ao criar um *trigger* para uma tabela se deve escolher entre configurar o trigger para executar `BEFORE`(antes) ou `AFTER`(depois) dos comandos `INSERT`, `UPDATE` e `DELETE`.

## Sintaxe

```sql
CREATE TRIGGER trigger_name
BEFORE | AFTER INSERT | UPDATE | DELETE
ON table_name
FOR EACH ROW
trigger_body;
```

Este comando irá criar um trigger com o nome `trigger_name`, estará ligado à tabela `table_name`, e para cada linha afetada pelo comando irá executar o `trigger_body`.

## Exemplo

Considere a seguinte [tabela de pizzas](ddl_pizzas_trigger.txt)

##### Pizzas
| id_pizza|nome|preco|atualizada_em
|---|---|---|---|
|1|Marguerita|10|2026-10-21 15:36:47|
|2|Frango|20|2026-10-21 15:36:47|
|3|Calabresa|40|2026-10-21 15:36:47|

Vamos criar um trigger para anotar o momento em que uma pizza for atualizada.

```sql
CREATE TRIGGER update_timestamp
BEFORE UPDATE ON Pizzas
FOR EACH ROW
SET NEW.atualizada_em = CURRENT_TIMESTAMP;
```

Agora vamos atualizar o preço de da pizza de Marguerita:
```sql
UPDATE Pizzas
SET preco = 15
WHERE id_pizza=1;
``` 
##### Pizzas
| id_pizza|nome|preco|atualizada_em
|---|---|---|---|
|1|Marguerita|**15**|2026-10-21 **17:17:00**|
|2|Frango|20|2026-10-21 15:36:47|
|3|Calabresa|40|2026-10-21 15:36:47|

Podemos ver que o valor de `atualizado_em` foi modificado para 4 horas depois.

## Adicionando Em Outra Tabela

Vamos ver outro exemplo: queremos guardar todas as pizzas que forem deletadas da tabela de Pizzas. Vamos fazer um trigger que faz uma cópia das pizzas que forem deletadas para uma tabela `pizzas_deletadas`.



```sql
CREATE TRIGGER shadow_delete_pizza
AFTER DELETE ON Pizzas
FOR EACH ROW
INSERT INTO Pizzas_Deletadas (id_pizza, nome, preco, deletada_em)
VALUES (OLD.id_pizza, OLD.nome, OLD.preco, CURRENT_TIMESTAMP);
```

À seguir o resultado de deletar a pizza de id 1
```sql
DELETE FROM Pizzas
WHERE id_pizza=1
```

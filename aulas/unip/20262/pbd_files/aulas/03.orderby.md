# SELECT ORDER BY

O comando `ORDER BY` escolhe um parâmetro para que a sua pesquisa seja ordenada.

## Sintaxe

```sql
SELECT column1, column2, ...
FROM table_name
ORDER BY column1, column2, ... ASC|DESC;
```

Na sintaxe completa você usar no final do `SELECT` e pode escolher se quer uma ordenação ascendente (padrão) ou descendente.

Por exemplo

```sql
SELECT * FROM Alunos
ORDER BY nome;
```

Os alunos estarão ordenados por `nome` em ordem ascendente.

```sql
SELECT * FROM Alunos
ORDER BY nome DESC;
```

Os alunos estarão ordenados por `nome` em ordem descendente.


```sql
SELECT * FROM Alunos
ORDER BY nome DESC, sobrenome ASC;
```

Você pode ordenar por duas colunas, e escolher o sentido de cada uma delas. Neste caso será ordenado, primeiro pelo nome, e depois pelo sobrenome.

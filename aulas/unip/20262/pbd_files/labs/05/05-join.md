# Treinando `Join` Com Duas Tabelas


Usando o mesmo banco de dados dos últimos laboratórios, faça as seguintes pesquisas combinando dados de duas tabelas:

- Exiba a data de todos os pedidos com o nome de cada Pizza, **não incluindo** pizzas que não foram pedidas.
- Exiba a data de todos os pedidos com o nome de cada Pizza, incluindo pizzas que não foram pedidas.
- Exiba a data de cada pedido com o nome do cliente que fez o pedido

## Join com Agregação

- Exiba o nome de cada pizza e a soma de quantas foram pedidas e a soma de quanto foi a receita da pizza pedida.
- Exiba quantas pizzas cada pessoa pediu.
- Exiba quantas pizzas foram pedidas por bairro.

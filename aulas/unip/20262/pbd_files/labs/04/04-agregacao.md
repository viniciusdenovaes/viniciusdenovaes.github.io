# Treinando Funções de Agregação

Usando o mesmo banco de dados do último laboratório, faça as seguintes pesquisas com os seguintes cálculos:

- Exiba a média dos valores das Pizzas
- Exiba a média dos valores das Pizzas divididas por categorias de salgado, doce, etc...
- Exiba o valor da pizza mais barata.
- Exiba o valor da pizza mais barata de cada categoria.
- Exiba a quantidade de pizzas por categoria.
